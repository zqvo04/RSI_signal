# 펀딩비 · OI 극단 (정보성)

> [← README](../Readme.md) · 공통 규칙: [rules.md](rules.md)

| 항목 | 내용 |
| --- | --- |
| 대상 코인 | BTC · ETH · SOL · BNB · XRP (`DERIV_COINS`, `VWAP_COINS`와 동일) |
| 거래량·상위 TF 필터 | 적용 안 함 (신호가 아니므로) |
| 검사 건수 | 코인당 펀딩 1 + OI 1 = 10건/실행 |

**매매 신호가 아닙니다.** LONG/SHORT 방향이 없고 "지금 파생 지표가 평소와 크게 다르다"는 **사실만** 알립니다. 기존 `🚨 신호 요약`과 **별도 Telegram 메시지**(`📊 파생 지표 극단`)로 전송되며, 해석(청산 위험·반전 가능성 등)은 넣지 않습니다.

## 1. 극단 판정 (공통)

- 고정 임계값 대신 **그 코인 자신의 최근 이력 대비 순위**로 판정합니다. 코인마다 펀딩·OI 스케일이 다르기 때문입니다.
- 현재값이 이력의 상위 또는 하위 꼬리에 들어가면 극단입니다. 꼬리 크기는 펀딩 **5%**(`EXTREME_TAIL`), OI **1%**(`OI_EXTREME_TAIL`)입니다. 이력이 30개 미만이면 판정하지 않습니다.
- **진입 시 1회 + 재발화 차단**: 직전 `quiet`개 값 중 같은 방향 극단이 하나라도 있으면 알리지 않습니다. 펀딩은 직전 1회, OI는 직전 **24시간**(`OI_QUIET_HOURS`)입니다. 반대편 극단으로 넘어가면 다시 알립니다.
- 상태를 저장하지 않습니다. 매 실행 조회한 이력만으로 계산합니다.

## 2. 펀딩비

| 항목 | 기준 |
| --- | --- |
| 데이터 | `fetchFundingRateHistory` 최근 90회 (8h 정산 기준 약 30일) |
| 발화 시점 | 정산(00/08/16 UTC) 후 첫 스캔. 최신 정산이 15분 이내일 때만 (`SCAN_INTERVAL_SECONDS`) |
| 최소 크기 | \|rate\| ≥ **0.02%** (`FUNDING_MIN_ABS`). 한산한 장에서 순위만 높은 작은 값은 제외 |
| 부호 일치 | 상위 극단은 양수, 하위 극단은 음수일 때만 (양수 → **롱 쏠림**, 음수 → **숏 쏠림**) |

## 3. OI (미결제약정)

| 항목 | 기준 |
| --- | --- |
| 데이터 | `fetchOpenInterestHistory` 1h **768개**(`OI_HISTORY_LIMIT`). OKX가 호출당 100개만 주므로 `until`로 약 8회 페이징 → 24h 변화율 744개(약 31일) |
| 측정값 | 24시간 전 대비 OI 변화율 (`OI_CHANGE_HOURS = 24`) |
| 발화 시점 | 확정된 1h 구간 종료 후 첫 스캔. 진행 중인 구간은 제외. 첫 페이지에서 "방금 닫힌 구간"이 아니면 나머지 페이지는 조회하지 않음 (평소 스캔은 1회 호출) |
| 판정 | 변화율이 상위 1% → **급증**, 하위 1% → **급감** (직전 24시간 재발화 차단) |
| 함께 표시 | 완성 1h 캔들 기준 24h 가격 변동률 (이미 받은 데이터 사용, 추가 호출 없음) |

## 4. 메시지 예시

```
📊 파생 지표 극단 (UTC 08:00)
BTC
 · 펀딩비 +0.081% (직전 89회 중 상위 2%) — 롱 쏠림
 · OI 24h +12.3% (직전 743시간 중 상위 1%) — 급증 | 가격 24h +4.1%
SOL
 · 펀딩비 -0.064% (직전 89회 중 하위 4%) — 숏 쏠림
```

괄호 안 순위는 "직전 N개 중 상위/하위 몇 %"이며, N은 실제 조회된 이력 개수입니다.

## 5. 백테스트 결과

OKX 실데이터, 5코인. 기간: 펀딩 2026-08-19~11-21(평가 64일), OI 2026-09-22~11-21(31일 기준선을 뺀 평가 28일). 현재 코드의 판정 함수를 그대로 재생했습니다.

| 항목 | 초기 설정 | 현재 설정 |
| --- | --- | --- |
| 펀딩 (하한 / 5코인 합) | 0.03% → **1건**/64일 | 0.02% → **5건**/64일 (0.08건/일) |
| OI (기준선 / 꼬리 / 차단) | 100시간 / 5% / 없음 → **6.55건/일**(코인당 1.3) | 744시간 / 1% / 24시간 → **0.96건/일**(코인당 0.19) |
| OI 재발화 (같은 코인 6시간 내) | 366건 중 146건 (40%) | 27건 중 3건 |

- OKX 펀딩은 |rate| 중앙값이 0.004~0.009%, 93일 최대 0.043%라 0.03% 하한에서는 알림이 거의 나오지 않았습니다. 0.01%로 내리면 코인당 월 약 1.8건, 0.02%는 월 약 0.5건 수준입니다.
- OI는 24h 변화율이 겹쳐 움직여서 짧은 기준선에서 같은 극단이 반복 발화했습니다. 기준선·꼬리·재발화 차단을 함께 조정해 하루 약 1건으로 줄였습니다. 알림이 나는 시각 기준 별도 메시지는 하루 약 1통입니다.

## 6. 한계와 확인 필요 사항

- 표본이 짧습니다(펀딩 64일, OI 28일). 시장 국면에 따라 빈도가 달라집니다. 알림이 이후 가격과 얼마나 관련 있는지는 검증하지 않았습니다.
- OKX OI 이력의 타임스탬프는 **구간 시작 시각**임을 확인했습니다. 다만 정각 직후 직전 구간 값이 90초 안에 ±0.15~0.3%가량 흔들리고, 새 구간이 나타났다 사라지기도 합니다. 정각 스캔은 덜 확정된 값을 볼 수 있어 극단 경계에서 판정이 바뀔 수 있습니다.
- OKX OI 이력은 약 60일까지만 제공됩니다. 744시간 기준선은 그 범위 안입니다.
- 코인당 OI 이력 조회가 발화 시점에 약 8회로 늘어납니다(스캔당 평균 1회, 정각 직후 스캔만 8회).
- 펀딩 주기가 8h가 아닌 종목(향후 `DERIV_COINS` 확장 시)은 "직전 90회"가 30일이 아닐 수 있습니다.

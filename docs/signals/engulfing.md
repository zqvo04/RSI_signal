## 1. 조건

| 방향 | 핵심 조건 |
| --- | --- |
| 📈 Bullish | 음봉→양봉 감싸기, 종가 > EMA20, 저가가 직전 N봉 최저가 이하(0.5% 허용) |
| 📉 Bearish | 양봉→음봉 감싸기, 종가 < EMA20, 고가가 직전 N봉 최고가 이상(0.5% 허용) |

| 타임프레임 | 바디 강도 (현재/직전 바디) | 직전 N봉 |
| --- | ---: | ---: |
| 1h | 1.1× | 8 |
| 4h · 1d | 1.0× | 5 |

## 2. 추가 필터

도지 차단 · 꼬리 과다 차단 · 직전 3봉 내 같은 방향 Engulfing 차단 · 종가가 바디 중간 이상(Bullish)/이하(Bearish)
